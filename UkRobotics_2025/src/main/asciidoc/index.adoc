== Four Freedoms

* The freedom to run the program as you wish, for any purpose
* The freedom to study how the program works, and change it to make it do what you wish. Access to the source code is a precondition for this.
* The freedom to redistribute copies so you can help others
* The freedom to distribute copies of your modified versions to others

[.notes]
--
Definition of Free Software, Richard Stallman
--

== License

* Permissive
* Copyleft

[.notes]
--
* Permissive: Do what you like, for whatever purpose you like
* Copyleft: If you create a derived work, then you *must* also publish the source

== Self governing project communities

* Report quarterly to the Board, which ensures that projects are operating ...
** Legally
** With adequate oversight
** According to ASF principles

[.notes]
--
* Three active PMC members (More about PMCs in a moment)
* Board does *not* give technical input
--

== Ladder

* PMC
* Committer
* Contributor
* User

[.notes]
--
* Users are critical to projects, since they shape what gets created
* Contributors have input in how it gets created
* Committers have earned trust, and can directly make changes
* PMC members vote on releases, and on new community members
--

== Membership organization

* Members elect new members
* Members elect the board
* The Board creates new projects, and retires old ones
